# OmniNPC

AI characters that remember different things, and cannot read each other's memories.

## What this is

Most game characters either forget you between conversations, or share one global
memory where everyone somehow knows everything. Neither resembles how information moves
through a real place.

OmniNPC is a backend where each character has its own memory, and where what one
character knows is decided by a database query rather than by hoping the model behaves.
The demo is a bank branch: tell the manager something in private and the teller cannot
find out, but issue a security clearance and the guard learns about it without anyone
telling them directly.

The full demo, and how much of it is built, is in
[`docs/SCENARIO.md`](docs/SCENARIO.md).

## How it works

When a character is spoken to, the backend searches its memory, builds a prompt from
whatever came back, and sends that to a language model.

Memory comes in two kinds. A **private memory** carries one character's id, and the
search only returns rows carrying the id of the character doing the searching. A **branch
announcement** carries no owner, and instead lists the roles allowed to see it, so any
character holding one of those roles finds it.

Because a character can only be told what its search returned, a private memory that is
never returned cannot appear in another character's answer. The rule is enforced where
the data is read, not by instructing the model to keep secrets.

Searches match on meaning rather than words, so asking about "that secure storage room"
finds an earlier conversation about the vault.

## Running it

You need Docker, a CockroachDB Cloud cluster, and LM Studio with a model loaded.

```bash
# CockroachDB Cloud requires TLS, so fetch the cluster certificate once
curl --create-dirs -o $HOME/.postgresql/root.crt \
  'https://cockroachlabs.cloud/clusters/<cluster-id>/cert'

cp backend/.env.example backend/.env      # set COCKROACHDB_URL and LM_STUDIO_API_KEY
psql "$COCKROACHDB_URL" -f schema/init.sql
psql "$COCKROACHDB_URL" -f schema/seed.sql

docker compose up --build backend
```

The API is on `http://localhost:8000`, with an interactive reference at `/docs`.

To check that the memory rules hold, run the test script. It talks to the characters,
then confirms that the teller cannot reach the manager's private conversation and that
the guard can reach the clearance:

```bash
backend/.venv/bin/python scripts/mini_scenario.py
```

## Settings

All of these live in `backend/.env`.

| Variable | Default | Purpose |
|---|---|---|
| `COCKROACHDB_URL` | none | Cluster connection string. Required |
| `LLM_PROVIDER` | `lmstudio` | One of `lmstudio`, `gemini`, `bedrock` |
| `LM_STUDIO_BASE_URL` | `http://host.docker.internal:1234` | Use `localhost` when not in Docker |
| `LM_STUDIO_API_KEY` | none | From LM Studio's Developer tab |
| `LM_STUDIO_MODEL_ID` | `google/gemma-4-12b` | Which local model to use |
| `GEMINI_API_KEY` | none | Only when using Gemini, whose free tier allows 20 requests a day |

## Layout

| Path | What is in it |
|---|---|
| `backend/app/memory/` | Searching memory, saving it, publishing announcements |
| `backend/app/prompts.py` | Building the prompt, keeping private memory and announcements distinct |
| `backend/app/providers/` | LM Studio and Bedrock |
| `backend/app/routers/` | The HTTP endpoints |
| `schema/` | Tables, vector index, demo characters |
| `scripts/mini_scenario.py` | Automated check that the memory rules hold |
| `docs/SCENARIO.md` | The demo, and what is built |

## If something breaks

| What you see | What it means |
|---|---|
| `root certificate file ... does not exist` | The cluster certificate was not downloaded. Docker mounts it from `~/.postgresql/root.crt` |
| `expected 384 dimensions, not N` | The embedding model and the database column disagree about vector size |
| Requests hang instead of failing | The model provider key is missing or wrong |
| `INVALID_PAYMENT_INSTRUMENT` | Bedrock only. Anthropic models are billed through AWS Marketplace, which needs a verified payment method |

```bash
docker compose logs backend --tail=50
```

## Security

`backend/.env` holds database credentials and API keys, and is excluded from Git. If one
is ever committed, rotate it rather than deleting the commit. The policy in
`iam/omninpc-policy.json` grants only model invocation and speech synthesis, not account
wide access.
