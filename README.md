# aws-cockroachdb

Project for the **CockroachDB × AWS Hackathon: Build with Agentic Memory** (Devpost, deadline Aug 18, 2026).

## About the Hackathon

CockroachDB and AWS challenged builders to create the next generation of agentic applications — agents that think, act, and remember reliably, globally, at any scale. The goal: build an agentic application that uses **CockroachDB as its persistent memory layer**, deployed on **AWS**, using at least two CockroachDB tools (Cloud Managed MCP Server, Distributed Vector Indexing, ccloud CLI, or the Agent Skills Repo) and at least one AWS service (Bedrock, Lambda, ECS/EKS, S3, SageMaker, etc.).
